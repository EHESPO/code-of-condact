# EHEPS Developer Documentation

Welcome to the official repository for **EHEPS International Organization** developer documentation.

This repository contains documentation, guides, APIs, examples, and technical resources for EHEPS platforms, research projects, artificial intelligence initiatives, humanitarian technology, and open-source software.

* https://eheps.com

## Contributing

We welcome contributions from developers, researchers, educators, volunteers, and partners.

Before submitting changes, please:

* Follow the project's coding and documentation standards.
* Write clear and accurate technical documentation.
* Test examples where applicable.
* Respect our Code of Conduct.
